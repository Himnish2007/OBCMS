Email (SMTP) Configuration

Required for real email delivery of alerts and reports. Without this configured, emails are logged only (not actually sent).

SMS Configuration

SMS delivery requires a paid SMS gateway account (e.g. Twilio, MSG91) — enter the provider details here once you have one. Until then, SMS attempts are logged only, not sent.

Data Source

Switch between simulated data and live RUT pushes once the hardware is wired up — it switches instantly, no redeploy needed.

RUT Device Assignment

A RUT router is mobile hardware — it moves between trains, not fixed to one coach. Register each physical RUT once, then reassign it here whenever it's moved to a different coach. No redeploy needed.

Push Contract (for the RUT's Lua script)

Have the RUT's Lua script HTTP-POST this JSON to /api/ingest/push using the device's own API key — the same pattern used in LOCO TM CMS / EMU TM.

{
  "apiKey": "<this device's API key>",
  "speed_kmph": 62,
  "axles": [
    { "axle_number": 1, "vibration_g": 0.42, "temperature_c": 38.5 }
  ],
  "piccu_status": { "WLI": "Online", "CCTV": "Fault" },
  "telemetry": [
    { "param": "Battery_Voltage_V", "value": 110.2, "unit": "V" }
  ]
}
